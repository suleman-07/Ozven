# Ozven Storefront

Customer-facing e-commerce storefront for the Ozven premium packaging brand.

## Stack

- Vite + React 18
- React Router v6
- Tailwind CSS
- Axios

## Setup

```bash
cd ozven-storefront
npm install
cp .env.example .env
npm run dev
```

Set `VITE_API_BASE_URL` to your public API base (default `http://localhost:5000/api/public`).

## Scripts

- `npm run dev` — local development
- `npm run build` — production build
- `npm run preview` — preview production build
